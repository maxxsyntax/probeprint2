# Consumer-premises-equipment SSID keyword -> operator -> market.
#
# format: keyword|operator|countries|scope
#
# scope tells you how much the match is worth:
#   country  one national market. The strongest residential-origin signal this
#            pipeline produces -- a device probing for a Bouygues Bbox has a
#            home connection in France.
#   region   one operator across a coherent set of markets (Telefonica across
#            Iberia and Latin America). Narrows to a region, not a country.
#   global   present in many unrelated markets. Nearly worthless for origin.
#   vendor   a hardware manufacturer, not an operator. Carries NO geography --
#            listed so the pass can refuse to claim one.
#   academic not CPE at all, but a strong affiliation signal.
#
# Keywords are matched case-insensitively as substrings of the decoded SSID,
# matching how categorize() works. They are literals to be matched against
# names on the air, so they are exempt from the American English rule.
#
# Sources: operator brand names for default router SSIDs. Where an operator
# trades under one brand in several countries the countries are listed and the
# scope is 'region' rather than 'country'.
