# Language markers for Latin-script SSIDs.
#
# format: word|languages|scope
#
# check_language() in ssid_intel_functions.sh detects languages by SCRIPT --
# it matches UTF-8 byte ranges for Cyrillic, Arabic, Hebrew, Kana, Hangul and
# Greek. That leaves every Latin-script language completely invisible: a German
# or Spanish SSID written in ASCII is indistinguishable from an English one to
# that pass. On one real collection it found 15 Kanji and 1 Greek across the
# entire corpus while thousands of Spanish and German names sat in
# OTHER_UNKNOWN. This list closes that gap.
#
# scope decides how strong a claim the match supports:
#   language   distinctive to one language. Sufficient on its own.
#   family     shared across a language family -- 'casa' is Spanish, Italian,
#              Portuguese and Romanian. Narrows to the family, not the language.
#   ambiguous  also an ordinary English word, or shared across unrelated
#              families. Recorded but never sufficient by itself, because SSIDs
#              are mostly English and a false positive here invents a
#              nationality for somebody.
#
# Vocabulary is chosen for the domain SSIDs actually use -- home, family,
# network, guest, rooms, colors, pets -- not general word frequency. Accented
# and unaccented spellings are both listed because router config screens
# frequently strip diacritics.
#
# Words shorter than four characters are only included when highly distinctive,
# since short tokens collide with everything.
